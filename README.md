# Sistema de Gestión de Investigación Clínica (Clinical Research Management System)

[![Java](https://img.shields.io/badge/Java-17+-blue?logo=java)](https://www.java.com)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Aplicación de escritorio desarrollada para un laboratorio de análisis clínicos, pensada para organizar de forma simple pacientes, profesionales y estudios clínicos. Este proyecto forma parte de la materia _Programación II_ y sigue el modelo **MVC** junto con principios de programación orientada a objetos.

---

## ✨ Funcionalidades

- Gestión completa de entidades: pacientes, profesionales y estudios (crear, editar, eliminar, consultar).
- Relación entre datos: cada estudio está vinculado a un paciente y a un profesional.
- Sistema de búsqueda: permite filtrar información por fecha, estado, paciente o profesional.
- Persistencia de datos: la información se guarda automáticamente en archivos de texto.
- Interfaz gráfica: interfaz sencilla basada en GUI para facilitar el uso.

---

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** Java 17+
- **Interfaz gráfica:** Swing
- **Arquitectura:** MVC (Modelo - Vista - Controlador)
- **Persistencia:** Archivos locales con Java I/O
- **Gestión del proyecto:** Maven o Gradle (opcional)

---

## 📌 Notas

- No requiere base de datos externa.
- Diseñado como proyecto académico, pero funcional para casos simples.
- Fácil de extender o modificar.
